# pagina-web-frontend
El repositorio contiene un Linktree y una página web trabajada unicamente con Frontend (HTML, CSS y JS). Esta misma simula una pagina web perteneciente a una ONG que busca salvar los bosques Argentinos de todo el país.

The repository contains a Linktree and a website built solely with frontend development (HTML, CSS, and JS). This website simulates a site belonging to an NGO that aims to save Argentina's forests throughout the country.
